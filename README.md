# planb-vt 조직 공용 파일

이 저장소에는 **이슈·합치기 요청(PR) 양식**만 들어 있습니다. 조직의 다른 저장소가 자기 양식을 따로 가지고 있지 않으면 여기 있는 양식이 쓰입니다.

깃허브는 이 공용 양식이 동작하려면 이 저장소가 공개여야 한다고 요구합니다. 그래서 여기에는 **양식 파일만** 둡니다. 제품 코드와 내부 문서는 비공개 저장소에 있습니다.

```
.github/
├─ ISSUE_TEMPLATE/
│  ├─ config.yml      빈 이슈 금지 + 보드 링크
│  ├─ 1-task.yml      작업
│  ├─ 2-bug.yml       버그
│  └─ 3-idea.yml      아이디어
└─ pull_request_template.md
```

양식을 고치려면 이 저장소에서 고칩니다. 저장소 하나만 다르게 쓰고 싶으면 그 저장소에 같은 이름의 파일을 두면 됩니다(그 저장소에서는 공용 양식이 무시됩니다).
